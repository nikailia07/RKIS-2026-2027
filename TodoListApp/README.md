TodoListApp

Консольное приложение для управления списком задач на C#.

Возможности

* help — показать список доступных команд.
* profile — вывести данные пользователя.
* add "текст" — добавить новую задачу.
* view — показать список задач, их статусы и даты изменений.
* done <индекс> — отметить задачу выполненной.
* delete <индекс> — удалить задачу.
* update <индекс> "текст" — изменить текст задачи.
* exit — завершить программу.

Особенности

* Задачи хранятся в массиве todos.
* Статусы выполнения хранятся в массиве statuses.
* Даты создания и последнего изменения хранятся в массиве dates.
* Все три массива расширяются синхронно.
* При изменении статуса или текста задачи обновляется дата.
* Индексация задач начинается с 0.

Пример использования

add "Купить хлеб"
add "Выполнить лабораторную"
view
done 0
update 1 "Завершить лабораторную"
delete 0
view
exit

TodoList App

Консольное приложение для управления списком задач.

Новые возможности (Лекция 5)

Программа поддерживает гибкое управление через флаги командной строки.

Команды:
* `add [текст]` — добавить обычную задачу. Текст можно писать в кавычках.
* `add --multiline` или `add -m` — добавить многострочную задачу. Ввод продолжается до команды `!end`.
* `view` — показать список задач в виде таблицы.
  * `-i` или `--index` — показать ID задачи.
  * `-s` или `--status` — показать статус (Выполнена/Не выполнена).
  * `-d` или `--update-date` — показать дату последнего изменения.
  * `-a` или `--all` — показать все столбцы одновременно.
  * Флаги можно комбинировать: `view -is`.
* `read <idx>` — показать полный текст задачи, ее статус и дату изменения по ID.
* `help` — вывести справку по командам.
* `exit` — выйти из программы.
